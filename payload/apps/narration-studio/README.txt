MELLISH NARRATION STUDIO

Turns pasted text, books, scripts and comic pages into editable voice projects.
It can identify narrators and likely speakers, assign different Kokoro voices,
generate individual WAV lines, combine parts, and export dialogue data for
Unity or VRChat.

The Comic Reader tab displays an imported page while playing its generated
voice lines in order. Double-click a Speaker cell in the Script tab, or use
the Speaker drop-down below the table, to correct a character assignment.

The Text Reader tab reads pasted text without requiring a project. Select a
voice card, use Preview to hear its sample, and press Read Aloud. Preview and
reading audio is cached under the contained assistant cache folder.

INSTALL
1. Extract the complete ZIP.
2. Run "Install Narration Studio.cmd".
3. Enter the Mellish Portable AI Assistant folder.
4. Run "Start Narration Studio.cmd" from apps\narration-studio.

RECOMMENDED USE
Import -> review uncertain speakers -> assign voices -> preview a few lines ->
generate -> combine/export.

The application never treats speaker guesses as guaranteed. Review Unknown and
low-confidence lines, especially for comics and complicated prose.

See README.md for the full manual, MCP tools, formats and limitations.
